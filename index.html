How I work

Curiosity, with
a method.

Understand the system. Question the assumptions. Make the result useful to the people building it.

01

Application security

+

I look at how authentication, access controls and application logic behave in practice, combining manual testing with source code review.

  • Web applications and APIs
  • Authentication, sessions and authorization
  • Injection, SSRF and exploit chains
  • Burp Suite, code review and reproducible evidence
02

Active Directory

+

I investigate relationships between identities, permissions and services to understand how individual misconfigurations can become attack paths.

  • SMB and LDAP enumeration
  • Kerberos, delegation and ACL abuse
  • Privilege escalation and lateral movement
  • BloodHound, Impacket and NetExec
03

Research & tooling

+

I build tools for repetitive work and use hands-on research to keep learning. My scripting includes Python, Bash and PowerShell; I’m developing my Go fundamentals through personal projects with AI assistance.

  • Vulnerability analysis and proof of concepts
  • Automation for security workflows
  • Clear reports and practical explanations
  • Continuous learning through labs and research
