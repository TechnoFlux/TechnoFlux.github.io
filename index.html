01 Focus

Web Application

Authentication and session handling, broken access control and IDOR, injection (SQL, command, template), SSRF, deserialization, and file upload chains. Source-assisted where the code is available, black box where it isn't.

Active Directory

Domain enumeration over SMB and LDAP. Kerberoasting, AS-REP roasting, and delegation abuse. ADCS misconfigurations (ESC1 through ESC8), ACL and DACL abuse paths, LAPS, and movement across trusts.

Tooling/Scripting

Tooling for the parts of an engagement that repeat. I write mine in Go, Rust, and Python, and read most other languages well enough to follow a codebase during source review.

02 Work

Auto AD Recon

★ 19 Python

A modular Python wrapper around NetExec for Active Directory enumeration over SMB and LDAP. Built for internal pentests, red teams, and AD-heavy CTFs. It runs the enumeration I'd otherwise type by hand at the start of every engagement.

  • Password, NTLM hash, and null session authentication
  • Parallel execution of built-in and custom NetExec modules
  • ADCS misconfiguration detection, ESC1 through ESC8
  • ACL parsing for GenericAll, WriteDACL, and similar rights
  • LAPS credential extraction, trusts, group membership, machine quota
  • Optional BloodHound-compatible collection
